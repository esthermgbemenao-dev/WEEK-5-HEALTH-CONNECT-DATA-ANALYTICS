 HealthConnect Clinic – Week 5 Data Analytics

## Project Overview

This project is part of the AnalystLab Africa Experience Lab, Week 5.

The project focuses on improving patient appointment attendance and healthcare support at HealthConnect Clinic through data analysis and evidence-based insights.

## Week 5 Focus

- Data preparation and quality assessment
- Exploratory data analysis (EDA)
- KPI development
- Appointment attendance and no-show analysis
- Business insights and recommendations
- Initial dashboard development

## Dataset

The analysis uses the HealthConnect Clinic appointment dataset containing 5,000 appointment records and 18 variables.

Key variables include:

- Appointment outcome
- Booking lead time
- Previous appointments
- Previous no-shows
- Reminder sent
- Reminder channel
- Distance to clinic
- Waiting time
- Appointment type
- Age and age group
- Appointment day and time

## Key KPIs

- No-Show Rate: 48.46%
- Attendance Rate: 46.28%
- Cancellation Rate: 5.26%
- Average Booking Lead Time: 29.64 days
- Reminder Effectiveness: 47.63%

## Key Findings

- No-shows were the largest appointment outcome.
- Longer booking lead times were associated with higher no-show rates.
- Appointments with previous no-shows showed higher future no-show rates.
- Appointments where reminders were sent had a higher attendance rate than appointments without reminders.
- No-show patterns varied across age groups and appointment types.

## Tools Used

- Microsoft Power BI
- Power Query

## Project Goal

The goal is to use appointment data to identify patterns associated with missed appointments and provide actionable insights that can support HealthConnect Clinic in improving attendance and patient support.
